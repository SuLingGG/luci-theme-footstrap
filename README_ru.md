# luci-theme-footstrap (китайская ветка)

Этот репозиторий — форк [VizzleTF/luci-theme-footstrap](https://github.com/VizzleTF/luci-theme-footstrap),
в котором выполнены две доработки:

- добавлен перевод на упрощённый китайский язык, распространяемый отдельным пакетом
  `luci-i18n-footstrap-zh-cn`;
- сборка сведена к единственному пути — официальному SDK; пакеты распространяются через
  GitHub Release, без owfeed и без e2e на реальных роутерах.

Поведение и внешний вид темы совпадают с оригиналом; [документация для разработчика](docs/README.md)
применима и здесь.

## Возможности

| Свойство | Подробности |
|---|---|
| Зависимости | Только `luci-base` |
| Охват | Оформляет каждую страницу LuCI, включая сторонние `luci-app-*` |
| Приложения со своими стилями | Не переопределяет стили, заданные приложением |
| Мобильные устройства | Работает на телефоне и устанавливается на домашний экран |
| Внешний вид | Раскладка, палитра, плотность, размер текста, скругления, обои, прозрачность — более двадцати настроек, применяются без перезагрузки страницы |
| Языки | Упрощённый китайский, русский, испанский — каждый отдельным пакетом |

## Требования

| Система | Поддержка |
|---|---|
| OpenWrt 25.12 и новее (менеджер пакетов `apk`) | Пакет `.apk` |
| OpenWrt 24.10.3 и новее (менеджер пакетов `opkg`) | Пакет `.ipk` |
| OpenWrt 24.10.0 – 24.10.2 | Не поддерживается: в этих выпусках отсутствует компонент LuCI, который использует тема. Требуется обновление OpenWrt |
| OpenWrt 23.05 | Доступна только версия 0.14.2 из оригинального репозитория; пакетов для неё здесь нет |

Браузер: Chrome 120, Firefox 121, Safari 17.2 или новее. Версию OpenWrt показывает команда
`cat /etc/openwrt_release` на роутере.

## Установка

Этот репозиторий не публикует фид пакетов и распространяет пакеты только через GitHub Release,
поэтому установка состоит из двух шагов: загрузка и установка.

### 1. Загрузка пакета

Откройте страницу [Releases](https://github.com/SuLingGG/luci-theme-footstrap/releases/latest)
и скачайте файл, соответствующий вашей системе:

| Система | Файл |
|---|---|
| 25.12 и новее (apk) | `luci-theme-footstrap-<версия>-r1.apk` |
| 24.10 (opkg) | `luci-theme-footstrap_<версия>-r1_all.ipk` |
| Требуется китайский интерфейс | дополнительно `luci-i18n-footstrap-zh-cn` в том же формате |

При наличии `gh` файлы можно загрузить командой:

```sh
gh release download --repo SuLingGG/luci-theme-footstrap \
  --pattern 'luci-theme-footstrap*' --pattern 'luci-i18n-footstrap-zh-cn*' --dir /tmp/fs
```

> Почему не приведена однострочная команда `wget`: имя файла в Release содержит версию, а
> `releases/latest/download/<имя>` требует точного совпадения имени. Получение номера версии
> через GitHub API ограничено по IP источника (60 запросов в час; за NAT провайдера один IP
> используют многие). В оригинальном репозитории по этой причине заведён отдельный issue.

### 2. Установка

Передайте файл на роутер (`scp` или «Система → Программное обеспечение → Загрузить» в LuCI),
затем выполните:

```sh
# 25.12 и новее (apk)
apk add --allow-untrusted /tmp/luci-theme-footstrap-*.apk

# 24.10 (opkg)
opkg install /tmp/luci-theme-footstrap_*.ipk
```

`--allow-untrusted` относится только к подписи самого пакета: пакеты этого репозитория не
подписаны. Перед установкой можно проверить целостность загрузки по `SHA256SUMS` из того же
Release:

```sh
cd /tmp && sha256sum -c SHA256SUMS
```

### 3. Включение

После установки тема не переключается автоматически — её нужно выбрать один раз:

1. Откройте **Система → Система → Язык и тема**;
2. В поле **Тема оформления** выберите **Footstrap**;
3. Нажмите **Применить**. Страница перезагрузится в новой теме.

Для китайского интерфейса выберите там же **简体中文** в поле языка. Пункт появляется только
после установки языкового пакета.

### Обновление и удаление

Обновление выполняется теми же двумя шагами с файлом новой версии. Удаление:

```sh
apk del luci-theme-footstrap luci-i18n-footstrap-zh-cn     # 25.12 и новее
opkg remove luci-theme-footstrap luci-i18n-footstrap-zh-cn  # 24.10
```

LuCI автоматически вернётся к bootstrap; изменять **Тему оформления** заранее не требуется.

## Сборка

### В GitHub Actions

Рабочий процесс — [`.github/workflows/build-packages.yml`](.github/workflows/build-packages.yml),
поддерживает три способа запуска:

| Запуск | Результат |
|---|---|
| Вручную (Actions → 编译并发布主题包 → Run workflow) | Выбор `all` / `openwrt-24.10` / `openwrt-25.12`; пакеты выгружаются как artifact на 14 дней |
| Push в `main` | То же, собираются оба формата |
| Push тега `v*` | Сначала сборка, затем задание `release` публикует те же файлы в GitHub Release |

Путь сборки единственный: скачивается архив официального SDK, внутри выполняется
`make package/luci-theme-footstrap/compile`. Тема относится к noarch, поэтому пакет, собранный
SDK для x86_64, устанавливается на любую архитектуру, и матрица архитектур не нужна. SDK 24.10
даёт `.ipk`, SDK 25.12 — `.apk`.

### Локальная сборка

Требуется распакованный OpenWrt SDK ([страница загрузки](https://downloads.openwrt.org/releases/)):

```sh
VERSION=0.14.21 sh tools/ci-sdk-build.sh /path/to/sdk /tmp/out
```

Скрипт выполняет те же действия, что и CI: обновляет фид luci, подключает пакет к SDK, создаёт
`.config`, явно выбирает тему и китайский языковой пакет, собирает отсутствующие в SDK `po2lmo`
и `jsmin`, после чего складывает `luci-theme-footstrap` и все `luci-i18n-footstrap-*` в `/tmp/out`.

### Выпуск версии

1. Переименуйте `## [Unreleased]` в `CHANGELOG.md` в `## [<версия>] — <дата>` и внесите
   те же изменения в `CHANGELOG_ru.md` (`npm run changelog` проверяет согласованность файлов);
2. Закоммитьте изменения и поставьте тег на этот коммит:

   ```sh
   git tag v0.14.22
   git push fork v0.14.22
   ```

3. После завершения рабочего процесса в Release появятся `.ipk`, `.apk` и `SHA256SUMS`.
   Описание берётся из раздела `CHANGELOG.md` для соответствующей версии; при отсутствии
   раздела — из автоматически сформированного списка коммитов.

## Производительность

На том же роутере медианная страница отрисовывается в 3.03 раза быстрее, чем со стоковой темой bootstrap.
Обход 38 страниц занимает 4.9 с вместо 11.3 с.
Методика и данные: [docs/benchmark.md](docs/benchmark.md).
